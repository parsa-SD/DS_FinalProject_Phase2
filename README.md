- `scripts/database_connection.py`: Sets up and returns a database connection.
- `scripts/load_data.py`: Reads data from the SQL database into Pandas DataFrames.
- `scripts/preprocess.py`: Cleans, encodes, and normalizes the dataset.
- `scripts/feature_engineering.py`: Adds indicators and engineered features.
- `pipeline.py`: Runs the above scripts in sequence.


How to run the pipeline :

pip install -r requirements.txt
python pipeline.py
